## Configuração de ambiente

- `src/environments/environment.ts` (default/produção — `apiBaseUrl` ainda placeholder, atualizar quando existir host de produção) e `environment.development.ts` (`apiBaseUrl: 'https://localhost:7002'`), trocados via `fileReplacements` no `angular.json` conforme padrão do Angular CLI (`ng generate environments`).
- `AuthService` consome `environment.apiBaseUrl` para montar a URL de `POST /api/auth/login`. Próximos serviços (categoria, transação, cartão) devem seguir o mesmo padrão em vez de hardcoded paths.

TransactionType"`) mesmo com payload aparentemente correto. Investigação via `/swagger/v1/swagger.json` e chamadas reais à API local revelou que `docs/api-contract.md` estava **errado desde a origem**: todos os enums (`TransactionType`, `PaymentMethod`, `CardBrand`, `UserType`) trafegam como **número**, não como string literal, e todo campo `*Id` (`userId`, `transactionId`, `categoryId`, `creditCardId`, etc.) é **número**, não string. Isso nunca foi pego pelo `qa` porque MVP-1 e MVP-2 foram validados só com specs mockadas (`HttpTestingController`/spies), nunca contra a API real. Contrato corrigido primeiro (mapeamento nome↔número documentado, com nota explicando a correção e a evidência), depois `enums.model.ts` (union types → `enum` numérico), `auth.model.ts` e `transaction.model.ts` (`*Id` para `number`), `transactions.component.ts/html` (selects agora usam `[ngValue]` + labels em PT-BR, comparações de enum corrigidas, bug de falsy-check em `paymentMethod` — `Pix = 0` era tratado como "não informado"), e todos os specs afetados (`login`, `auth.service`, `transaction.service`, `transactions.component`). Validado com chamada real ao endpoint reproduzindo o payload exato reportado pelo usuário (`type: Saida`, `paymentMethod: Transferencia`) — agora recebe 200. 50/50 testes, build limpo. **Risco residual**: como a API real segue indisponível para o `qa` automatizado validar (specs de todos os tickets usam mocks), qualquer novo endpoint/campo deve ser conferido contra o swagger real antes de fechar o ticket, não só contra este documento.
